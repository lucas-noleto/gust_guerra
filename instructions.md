
# UI/UX REFINEMENT: MEDICAL EXCELLENCE & SOPHISTICATION

O design atual está muito genérico ("SaaS style"). Precisamos elevar para um patamar de "Medicina Premium/Luxo". Siga estas instruções estritamente para reformular a interface:

### 1. Paleta de Cores & Superfícies (Refined Palette)
- **Primary:** Azul Petróleo Profundo (#0A1A1F ou similar).
- **Secondary:** Cinza Grafite Suave (#2D3436).
- **Background:** Não use apenas um bloco preto. Use um "Off-white" (#F9FAFB) ou um Cinza muito claro para seções de conteúdo, intercalando com o Azul Petróleo em seções de destaque para criar ritmo visual. 
- **Contraste:** Texto principal sempre em #1A1A1A (quase preto) sobre fundos claros para máxima legibilidade e ar "Clean".

### 2. Tipografia (The Secret of Luxury)
- **Headers:** Use uma fonte Serifada (ex: Playfair Display, Merriweather, ou Lora) para os títulos principais. Isso transmite autoridade, tradição e sofisticação médica.
- **Body:** Use uma Sans-Serif moderna e leve (ex: Inter, Montserrat ou Lato) com peso 300 ou 400.
- **Hierarquia:** Aumente drasticamente a escala. O título da Hero deve ser imponente. Use `letter-spacing: -0.02em` nos títulos.

### 3. Espaçamento & Respiro (Whitespace)
- **Padding:** Dobre o espaçamento entre as seções. O design premium precisa de "ar". Use `padding: 120px 0` para seções de desktop.
- **Line-height:** No texto do corpo, use `line-height: 1.8` para facilitar a leitura e dar leveza.

### 4. Componentes Específicos (Redesign)
- **Cards (Seção 360°):** Remova as bordas grossas e fundos escuros pesados. Use fundos brancos com sombras extremamente sutis (soft shadows) ou apenas uma borda fina de 1px em cinza claro.
- **Acordeão (FAQ):** Remova o fundo escuro. Use um design minimalista: apenas uma linha fina separando as perguntas, com ícones "+" e "-" elegantes.
- **Botões (CTAs):** Remova o arredondamento exagerado (pills). Use `border-radius: 4px` ou `0px` para um visual mais sólido, masculino e arquitetônico. O botão principal deve ter um hover sutil (mudança leve de tom ou elevação).

### 5. Elementos Visuais Médicos
- **Grafismos:** Use linhas finas (hairlines) e divisores minimalistas.
- **Imagens:** Se houver containers de imagem, use bordas retas. Se usar ícones, use ícones de linha fina (Line Icons), nunca ícones preenchidos ou coloridos demais.

### 6. Estrutura da Hero
- A Hero atual está "encaixotada". Torne-a "Full Width" ou aumente o container. 
- O texto deve ser o protagonista absoluto. Se for usar foto do médico, ela deve estar integrada de forma orgânica, com fundo limpo.

### INSTRUÇÃO FINAL DE CODIFICAÇÃO:
"Pense como um designer de uma revista de luxo ou de um escritório de arquitetura de alto padrão, não como um desenvolvedor de aplicativos. O objetivo é SOLIDEZ e LIMPEZA."
